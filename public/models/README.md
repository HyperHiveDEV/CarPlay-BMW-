# Modèle 3D définitif

Déposez ici `bmw_f21_lci.glb` (BMW F21 LCI 3 portes, licence adaptée).
Au démarrage, l'application détecte le fichier : s'il est présent, il remplace la maquette provisoire.
Optionnel : `model-manifest.json` (copier `model-manifest.example.json`) pour adapter noms de nœuds, axes et angles.
Procédure complète : `docs/IMPORT_MODELE_3D.md`.
